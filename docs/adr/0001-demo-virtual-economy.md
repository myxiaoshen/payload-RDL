# 演示期采用纯虚拟币 + 永久 VIP

本模板的目标是可 fork 的开源演示，而非生产收款系统。经济层只使用站内 **平台币**（签到、管理调整、销售分成、悬赏托管等），不引入真实充值或支付网关；**VIP** 通过购买 **会员商品** 永久授予 `role=vip`，不做到期降级或权益配置表。

## Status

accepted

## Considered Options

- 纯虚拟币闭环（采纳）
- 虚拟币 + 可插拔充值 Provider / mock
- 真实支付（Stripe / 微信等）
- 永久 VIP 角色（采纳）
- 有期限会员（`vipExpiresAt`）
- 与角色解耦的权益配置表

## Consequences

- Fork 用户可在无商户号、无合规负担下跑通购买 / 下载 / 悬赏 / 会员演示
- 文档必须写明「不可提现、无真实支付、VIP 永久」，避免被当成生产收银模板
- 若将来要商用收款或订阅制，需要显式推翻本 ADR 并迁移订单与角色模型
